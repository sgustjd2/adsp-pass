# 출제 주제 조사 메모

기준일: 2026년 10월 12일 (Asia/Seoul)

주제 재구성340문항의 `source`는 원문 출처가 아니라 출제 주제 확인용 자료입니다. 공개 자료의 주제를 확인하고 문제·보기·해설을 새로 작성했습니다. 40~47회 각30문항, 48·49회 각35문항, 50회30문항에 자체 보충210문항을 더해 모든 회차를50문항으로 구성합니다. 보충은 해당 회차에서 실제 출제됐다는 확인 자료가 아닙니다.

## 회차별50문항 구성

- 40~47회·50회: 주제 재구성30 + 보충20 = 50.
- 48·49회: 주제 재구성35 + 보충15 = 50.
- 모든 회차는 학습 내용 기준으로1·2·3과목10·10·30문항이며 실제 시험 문항 순서를 복원한 배열이 아닙니다.
- 보충 문항의 ID는 `rXX-extra-NNN`, `supplement:true`, `source:'syllabus'`입니다. 공식 출제 범위에 맞춰 새로 만든 연습 문제이며 앱에서 보충 배지와 범위 출처를 표시합니다.
- 기존340문항의 ID·보기·정답을 유지했습니다. 50회 XML은1과목, 회귀 활용은3과목으로 바로잡았으며 현업 의사소통 사례는2과목의 분석 과제 협업으로 분류했습니다.
