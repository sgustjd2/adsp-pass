# 40~43회 출제 주제 확인 및 독립 문항 작성 기록

확인일: 2026-10-11. 각 회차에 30문항씩 총 120문항을 추가한다. 회차별 과목 구성은 데이터 이해 6, 분석 기획 6, 데이터 분석 18문항이다.

실제 시험의 50문항 전체, 원문, 선택지 또는 공식 정답을 복제한 자료가 아니다. 데이터에듀가 공개한 회차별 분석에서 **출제된 개념·주제**를 확인하고, 새로운 사례와 수치로 연습 문항 및 해설을 독립 작성했다. 같은 공개 주제에서 다른 적용 문항을 작성한 경우도 있다. 원문 순서·문항 번호는 재현하지 않는다.

## 시험일

40회 2024-02-24, 41회 2024-05-11, 42회 2024-08-10, 43회 2024-11-03. 시행일은 교육업체 자체 [이패스코리아 기출 복원 게시판](https://www1.epasskorea.com/board/restore_exam.asp?bg_idx=61&cate_idx=132708&link_idx=13906&nCate_idx=13270801&type=)의 회차별 시행일 표기를 확인했다. 데이터에듀 글의 2024년 11월 작성일과 실제 시험일을 구분했다.

## 접근 상태와 불확실성

40회 3과목 분석 2, 41회 2과목, 42회 각 과목은 확인 시 직접 열기에 403 응답 또는 접근 오류가 있었다. 로그인이나 유료 콘텐츠를 우회하지 않았다. 공개 웹 검색 결과가 제공하는 해당 페이지의 본문에서 제목·회차·출제 주제를 확인했다. `ROUND_SOURCES_40_43`에 공개 검색 본문 확인 여부를 기록했다. 나머지 출처는 공개 페이지 본문을 직접 읽었다. 출처의 향후 접근 가능성은 보장하지 않는다.

공개 복원 분석 자체는 응시 기억 자료이므로 정답·순서 변경 가능성을 고지하고 있다. 일부 정답 표기에는 설명이 부족하거나 알려진 개념과 어긋나는 부분이 있어 정답표를 복사하지 않았다. 특히 p값을 가설의 확률로 해석하지 않았고, 다중공선성 해결에 중복 변수 추가를 정답으로 사용하지 않았다. 신뢰구간에는 모수가 항상 포함되지 않으며, 잔차 대 적합값 패턴만으로 시간적 독립성을 확정하지 않는다.

- [NIST 정상성](https://www.itl.nist.gov/div898/handbook/pmc/section4/pmc442.htm): 일정한 평균·분산과 시차에 대한 설명.
