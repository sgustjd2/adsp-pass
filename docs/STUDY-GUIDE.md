# 과목별 핵심 요약노트·암기 정리

작성·확인일: 2026-10-11 (Asia/Seoul). 요약 본문: `dist/summary-notes.js`. 세부 확장·예제·도식: `dist/expanded-notes.js`. 암기·확인 질문: `dist/study-guide.js`.

이 자료는 핵심 개념을 빠르게 복습하는 독립 작성 요약이다. 교재·문항 원문·공식 해설을 전재하지 않았다. 암기 문구와 자가 확인 질문·수치는 자체 작성했으며 공식 암기법이나 전체 시험 범위의 완전한 대체 자료로 표시하지 않는다.

## 개념 근거

v1.5.0 확장은 R의 개별 함수 문서, PostgreSQL 키·트랜잭션·SQL 문서, Apache Hadoop, KDD 원 논문, 결측 연구자의 공개 교재, NIST, Penn State, scikit-learn의 일차 자료를 참조한다. 링크는 앱의 과목별 참고 자료와 `STUDY_SOURCES`에 연결한다. DataQ 링크는 과목 구성의 근거이며, SQL·레이크 비교·SMART식 목표 구체화 등의 보충 설명이 공식 세부 출제표에 모두 명시되었다는 주장은 하지 않는다. 예제 수치·상황·한국어 풀이·비유는 자체 작성했다.

## 오개념 방지

p값을 귀무가설의 확률로 해석하지 않는다. 기각하지 못함과 참임을 입증함을 구분한다. 상관·연관규칙과 인과를 구분하고, 큰 표본이 비표본 오차를 자동 해결하지 않는다고 명시한다. 표준화가 정규분포를 만드는 것이 아님을 적는다. 주성분의 무상관과 독립을 구분한다. 최소·최대 변환의 새 값이 0~1 밖에 나올 수 있음, DBSCAN의 서로 다른 밀도 한계, ReLU의 비활성 뉴런 가능성도 적는다.

DW의 비휘발성을 절대 갱신 불가로 설명하지 않는다. 조직 진단은 준비도·성숙도 축 순서를 고정하고, 단계 이름이 서로 다른 방법론을 섞지 않는다. 위험/통제의 세 가지 대응 연결은 시험 용어를 기억하는 틀로 표시하며 이 조치만으로 보호·공정성이 보장된다고 주장하지 않는다. 법률적 해석이나 개인정보 처리의 허용 여부를 안내하지 않는다.

## 이번 구성의 참고와 검증

사용자 첨부8페이지 PDF의 실제 요약 본문(1과목2페이지·2과목2페이지)을 렌더링하고 읽었다. 그 자료의 두 열·작은 글자를 모바일에 그대로 적용하지 않고, 단원→소제목→정의·표·절차의 형식을 한 열의 본문으로 구성했다. 내용 문장과 예시는 독립적으로 작성했다. 원본 PDF와 추출·렌더링 파일은 로컬 `tmp/`에만 있고 Git·배포에서 제외한다.

[꿈라CBT 회차별 화면](https://quiz.dreaming-ryan.com/subjects/adsp/rounds?mode=explain)과 학습 방식·50회 풀이 시작 화면을 브라우저에서 확인했다. 연도별 회차 탐색과 회차→모드 선택의 흐름을 반영했다. 이 사이트의50문항·이용자 평균을 앱의340개 재구성 자료에 적용하지 않는다. 사이트 문제 원문·해설·브랜드 자산을 가져오는 구현은 추가하지 않았다.

DBMS와 동시 접근은 [MongoDB NoSQL 설명](https://www.mongodb.com/resources/basics/databases/nosql-explained), [PostgreSQL 트랜잭션 격리](https://www.postgresql.org/docs/current/transaction-iso.html)를 확인했다. 나이브 베이즈는 [공식 문서](https://scikit-learn.org/stable/modules/naive_bayes.html)의 클래스 조건부 독립 가정으로 설명한다. 가명 처리의 법적 허용 여부를 판단하는 자료는 아니다. 정확도·정밀도는 측정의 맥락과 분류 지표의 맥락을 구분하며 둘이 항상 상충한다고 설명하지 않는다. 십진·이진 배수와 문자 인코딩의 차이도 구분한다.

모바일320/375, 태블릿768, 데스크톱1024/1440에서 가로 넘침과 본문·표의 글자 크기를 검사했다. 검색·빈 결과·초기화·단원 선택·암기 정답·본문 연결·연도별 회차→문항별 해설 경로를 확인했다. 인쇄용 CSS는 제공하지만 실제 휴대폰의 인쇄/PDF 저장 UI와 VoiceOver/TalkBack 전체 검수는 포함하지 않는다.

v1.4.0 그림 모드는 전 과목20/23/34개의 도식 존재와320/375/768/1024/1440px의 가로 넘침 없음을 확인했다. 모바일 기본16px·큰 글자19px, 320px 큰 글자4분면의 축 문구를 검증했다. 검색은 쉬운 예시도 포함한다. 검색 결과 없음→읽기 방식 전환→초기화, 시험 요약23항목 펼침, 암기 CRISP-DM→해당 그림 위치 이동을 확인했다. 3과목17개 SVG 개념도에 설명이 있으며 반복 신뢰구간 예시는19개 포함·1개 미포함을 확인했다. 로컬 서버를 종료한 뒤 페이지를 다시 열고3과목 회귀 그림·설명이 캐시로 재실행됨을 확인했다. 기존9개 풀이·타이머·백업 테스트와77항목 대응·렌더링·오프라인 파일 검증, 색 대비13쌍을 통과했다.

v1.5.0은 요약40/40/80개·전체160개의 그림·예제·풀이·출처 키와 오프라인 파일 구성을 검사했다. 모바일320px 큰 글자19px에서 전 과목의 가로 넘침 없음을 확인했고, 베이즈 표·공식·풀이와 R 행렬 코드 예제를 확인했다. 기본 글자는375px에서16px, 768/1440px에서17px이며 가로 넘침이 없었다. 예제 내용 검색·단원 필터·빈 결과·초기화, 시험 요약에서 풀이 기본 펼침과 그림 모드의 풀이 버튼을 확인했다. ROI·분산·표준오차·신뢰구간·베이즈·거리·PCA·연관규칙 수치를 검산했고, R 예제는 공식 함수 정의와 대조했다(R 실행 환경으로 검사했다고 주장하지 않는다). 서버를 종료한 뒤 앱을 새로 열어 신규 베이즈 그림·질문·풀이가 캐시에서 작동함을 확인했다. 기존9개 풀이·타이머·백업 테스트와 대비13쌍 검사를 통과했다. 긴 본문의 화면 밖 렌더링을 줄이며 인쇄에서는 전체 본문 렌더링을 복구한다.
