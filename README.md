# ADsP 포켓

휴대폰에서 설치하고 오프라인으로 공부할 수 있는 개인용 ADsP PWA입니다.

**앱 주소: https://sgustjd2.github.io/adsp-pass/**

## 설치

- iPhone: Safari에서 앱 주소 열기 → 공유 → 홈 화면에 추가
- Android: Chrome에서 앱 주소 열기 → 메뉴 → 앱 설치 / 홈 화면에 추가
- 처음 온라인으로 열고 **오프라인 준비 완료**를 확인하면 문제와 해설을 인터넷 없이 사용할 수 있습니다. 외부 출처 링크에는 인터넷 연결이 필요합니다.

## 기능

- 40~50회 **각 50문제(10·10·30), 총550개**와 해설. 공개 주제 재구성340개 + 출제 범위 보충210개
- 회차·과목 선택, 문제 검색, 오늘의 10문제(미풀이 우선)
- **요약·암기 메뉴**: 요약노트 200항목(1과목50 / 2과목50 / 3과목100)과 암기·확인 질문48항목
- **그림으로 이해**: 200항목 전체에 자체 도식·일상 예시·시험 개념 연결. DIKW, CRISP-DM, 모형 적합도, 혼동행렬에는 직접 생성한 큰 그림과 단계별 설명 추가. 나머지 항목도 내용별 SVG·HTML 도식 제공
- **꼼꼼히 이해하기**: 100항목에 판단 기준·원리·해석의 한계를 설명하는 210문단 추가. 단원별 공부 안내와 R 코드·결과 예제
- **요약 색상 구분**: 과목별 파랑·보라·주황, 상세 설명·공식·예제·주의점을 색과 제목으로 함께 구분. 초록색 없음
- **예제로 확인**: 전체 200항목에서 질문→풀이 펼치기. R 코드 결과·분산·표준오차·베이즈·신뢰구간·지니·연관규칙 계산과 업무 상황 판별 예제 포함
- **시험 요약**으로 전환하면 기존 정의·비교표·절차·공식을 펼쳐서 읽음. 그림 모드에서도 항목별 시험 핵심을 바로 펼칠 수 있음
- 단원 순서의 정의·키워드 표·절차·공식·주의점, 목차·검색, 과목별 인쇄·PDF 저장용 레이아웃
- 연도별 40~50회 선택 → 문항별 해설 또는 한 번에 채점 선택
- 답을 먼저 떠올린 뒤 정답 펼치기, 암기 비법에서 관련 개념으로 이동, 과목 문제 풀이 연결
- 풀이 시작 시 두 모드 선택: **문항별 해설 보기** / **한 번에 채점하기**
- 문항별 해설: 답 선택 → 정답 확인 → 해설 표시. 확인한 답은 잠김
- 한 번에 채점: 제출 전 답 수정·번호 이동 가능, 제출 후 점수·문제별 해설 표시. 회차 연습은 시간 제한 없음
- 실전 모의고사: 50문제, 1·2·3과목 10·10·30문제. 한 번에 채점 모드에서 90분 제한을 선택하면 자동 제출
- 90분 모의고사에는 총점 60점 및 과목별 40% 과락 조건 반영
- 즉시 채점, 자동 오답 기록, 북마크, 핵심 개념 요약
- 답안·위치 자동 저장, 절대 종료 시각 기반 타이머, 시간 종료 시 자동 제출
- 학습 이력, 시험 D-day, 큰 글자, JSON 백업·복원
- 개인정보·학습 기록은 브라우저의 localStorage에만 저장하며 서버에 보내지 않습니다.

## 문항의 성격과 출처

## 로컬 실행

Node.js 22 이상에서 별도 패키지 설치 없이 실행할 수 있습니다.

```sh
npm run dev
```

http://localhost:4173/adsp-pass/ 로 접속합니다. HTML 파일을 직접 여는 `file://` 방식은 모듈과 서비스 워커를 지원하지 않습니다.

```sh
npm run check
npm test
```

## 배포

`main`에 push하면 GitHub Actions가 문항·PWA 파일과 채점 로직을 검증한 뒤 `dist/`를 GitHub Pages에 배포합니다. 저장소 Settings → Pages의 Source는 **GitHub Actions**입니다. 모든 앱 경로는 상대 경로여서 `/adsp-pass/` 하위에서도 설치·오프라인이 작동합니다.

문항 파일: `dist/questions.js`, `dist/rounds-40-43.js`, `dist/rounds-44-47.js`, `dist/round-supplements.js`. 생성 그림은 `dist/images/`, 연결·대체 설명은 `dist/note-illustrations.js`에 있습니다. [그림 제작 프롬프트](docs/IMAGE-PROMPTS.md). 암기 자료는 `dist/study-guide.js`, 펼친 요약 본문은 `dist/summary-notes.js`에 있습니다. 문항 ID·선택지·정답과 기록 호환성을 유지합니다. 자료를 수정하면 `dist/sw.js`의 캐시 버전을 함께 올려 주세요. 새 서비스 워커가 대기 중이면 설정 화면에서 업데이트를 선택할 수 있습니다.

## 요약·암기 노트

모바일 하단 메뉴에서 **요약·암기**를 누르고 과목을 고릅니다. 요약노트는 소제목·정의·비교표·단계·공식·암기·주의점을 펼친 문서로 읽습니다. 목차·검색에서 단원을 고르거나 현재 과목의 본문을 검색할 수 있습니다. 암기 비법의 확인 질문은 정답을 접어 두고, 관련 개념 보기는 해당 요약 본문의 위치로 이동합니다.

요약 200항목과 암기48항목으로 핵심과 이해를 돕는 보충 개념을 복습하는 자료이며 전체 교재를 대신하지 않습니다. 설명·기억 문구·계산 예시는 자체 작성했습니다. [정리 범위·개념 근거·검수 기록](docs/STUDY-GUIDE.md)을 참고하세요. 모두 오프라인 저장하며 외부 링크는 인터넷이 필요합니다. 인쇄·PDF는 브라우저의 인쇄 창을 열며 선택한 과목·검색 결과와 펼쳐 둔 풀이를 출력합니다. 모바일 **내 기록**은 설정 → 내 기록 보기에서 열 수 있습니다.

## 기록 보관

기록은 기기·브라우저마다 독립적입니다. 개인의 오답·백업 파일은 저장소에 커밋하지 마세요. 다른 브라우저로 옮기거나 사이트 데이터를 지우기 전에 설정에서 JSON 백업을 내려받으세요. 공개 GitHub Pages 주소에 접속할 수 있는 사람은 앱을 사용할 수 있지만 개인 풀이 기록은 공유되지 않습니다.

## 검증

- 40~50회 문항 340개, ID·질문·보기 중복과 정답 범위, 출처·회차·과목 수량·오프라인 캐시 파일 검증
- 요약200항목·암기48항목의 ID·과목 수량·내용·출처·표 구조·관련 본문 연결, 전 항목 그림·예제 풀이, 100항목의 상세 설명210문단 검증
- 시험 10·10·30 추출, 90분 타이머, 과락, 미응답, 중복 집계, 오답 해제, 두 풀이 모드의 제출 전·후 기록, 구버전 백업 호환·이어풀기·날짜 검증 테스트
- 모바일 화면, 채점·해설, 북마크, 새로고침 이어풀기 확인
- 로컬 서버 종료 후 새로고침·문제 풀이·해설의 오프라인 동작 확인

실제 iOS·Android 기기 설치 확인은 사용자의 휴대폰에서 한 번 진행해야 합니다.
