# ADsP 포켓

휴대폰에서 설치하고 오프라인으로 공부할 수 있는 개인용 ADsP PWA입니다.

**앱 주소: https://sgustjd2.github.io/adsp-pass/**

## 설치

- iPhone: Safari에서 앱 주소 열기 → 공유 → 홈 화면에 추가
- Android: Chrome에서 앱 주소 열기 → 메뉴 → 앱 설치 / 홈 화면에 추가
- 처음 온라인으로 열고 **오프라인 준비 완료**를 확인하면 문제와 해설을 인터넷 없이 사용할 수 있습니다. 외부 출처 링크에는 인터넷 연결이 필요합니다.

## 기능

- 최근 50·49·48회 출제 주제 기반 재구성 문제 **100개**와 해설
- 회차·과목 선택, 문제 검색, 오늘의 10문제(미풀이 우선)
- 실전 모의고사: 50문제, 90분, 1·2·3과목 10·10·30문제
- 총점 60점 및 과목별 40% 과락 조건 반영
- 즉시 채점, 자동 오답 기록, 북마크, 핵심 개념 요약
- 답안·위치 자동 저장, 절대 종료 시각 기반 타이머, 시간 종료 시 자동 제출
- 학습 이력, 시험 D-day, 큰 글자, JSON 백업·복원
- 개인정보·학습 기록은 브라우저의 localStorage에만 저장하며 서버에 보내지 않습니다.

## 문항의 성격과 출처

**실제 시험 원문을 그대로 복원한 기출은행은 아닙니다.** 공개 후기에서 확인한 출제 주제로 문제·보기·수치·해설을 독립적으로 작성했습니다. 특정 회차를 선택해도 실제 시험지 전체 또는 같은 순서가 제공되는 것은 아닙니다. 복원 정보는 기억에 따른 자료이며 공식 정답을 보증하지 않습니다.

| 참고 회차 | 시험일 | 재구성 문항 | 주제 확인 자료 |
|---|---|---:|---|
| 50회 | 2026.08.08 | 30 | [응시 당일 후기](https://wankong0616.tistory.com/6) |
| 49회 | 2026.05.17 | 35 | [공개 복원 학습 정리](https://tgog-praise.tistory.com/69) |
| 48회 | 2026.02.07 | 35 | [데이터에듀 1과목](https://www.dataedupt.kr/sub/community/bbs1view1.php?cate=review&idx=510), [2과목](https://www.dataedupt.kr/sub/community/bbs1view1.php?idx=511), [3과목](https://www.dataedupt.kr/sub/community/bbs1view1.php?idx=512) |

49회는 복원 학습자의 2차 정리이므로 다른 회차보다 주제 확인 신뢰도가 낮습니다. 자료의 설명·문장을 재사용하지 않았으며 독립적으로 정답과 해설을 작성했습니다. 2026.10.11 기준 최신 완료 회차는 50회입니다.

일정·형식은 [교육업체 2026 일정 안내](https://mobile.tomatopass.com/landing/License5139.do)를 확인했습니다. 공식 DataQ 페이지는 조사 시 직접 조회가 되지 않았으므로 공식 사이트 검증 완료를 주장하지 않습니다. 최종 일정은 [DataQ](https://www.dataq.or.kr/www/sub/a_06.do)에서 확인하세요.

이지패스 앱의 모바일 문제 풀이 경험을 참고했으며 앱의 문항, 코드, 화면, 로고 등은 복제하지 않았습니다. 이 앱은 K-DATA 또는 이지패스와 관련이 없습니다.

## 로컬 실행

Node.js 22 이상에서 별도 패키지 설치 없이 실행할 수 있습니다.

```sh
npm run dev
```

http://localhost:4173/adsp-pass/ 로 접속합니다. HTML 파일을 직접 여는 `file://` 방식은 모듈과 서비스 워커를 지원하지 않습니다.

```sh
npm run check
npm test
```

## 배포

`main`에 push하면 GitHub Actions가 문항·PWA 파일과 채점 로직을 검증한 뒤 `dist/`를 GitHub Pages에 배포합니다. 저장소 Settings → Pages의 Source는 **GitHub Actions**입니다. 모든 앱 경로는 상대 경로여서 `/adsp-pass/` 하위에서도 설치·오프라인이 작동합니다.

문항 파일: `dist/questions.js`. 문항을 수정하면 `dist/sw.js`의 캐시 버전을 함께 올려 주세요. 새 서비스 워커가 대기 중이면 설정 화면에서 업데이트를 선택할 수 있습니다.

## 기록 보관

기록은 기기·브라우저마다 독립적입니다. 개인의 오답·백업 파일은 저장소에 커밋하지 마세요. 다른 브라우저로 옮기거나 사이트 데이터를 지우기 전에 설정에서 JSON 백업을 내려받으세요. 공개 GitHub Pages 주소에 접속할 수 있는 사람은 앱을 사용할 수 있지만 개인 풀이 기록은 공유되지 않습니다.

## 검증

- 문항 100개, ID·질문·보기 중복과 정답 범위, 회차·과목 수량 검증
- 시험 10·10·30 추출, 90분 타이머, 과락, 미응답, 중복 집계, 오답 해제, 백업·날짜 검증 테스트
- 모바일 화면, 채점·해설, 북마크, 새로고침 이어풀기 확인
- 로컬 서버 종료 후 새로고침·문제 풀이·해설의 오프라인 동작 확인

실제 iOS·Android 기기 설치 확인은 사용자의 휴대폰에서 한 번 진행해야 합니다.
